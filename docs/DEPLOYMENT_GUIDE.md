# Руководство по выгрузке OpenLogBook в веб на реальный сервер

Данная инструкция описывает, как бесплатно или за минимальную стоимость развернуть ваш персональный авиационный лётный логбук **OpenLogBook** в интернете, получить публичный адрес (с бесплатным защищенным протоколом HTTPS/SSL) и установить его на смартфон (iPhone/Android) или планшет iPad как полноценное мобильное приложение, работающее даже в кабине ВС без доступа в интернет (офлайн).

---

## Вариант 1: Бесплатный облачный деплой через Render.com (Рекомендуемый)

**Render.com** предоставляет бесплатный тарифный план (Free Tier), который идеально подходит для личного логбука. В репозитории уже настроен файл конфигурации `render.yaml`, поэтому деплой происходит буквально в несколько кликов.

### Шаг 1. Отправка вашего проекта на GitHub

1. Зайдите на [github.com](https://github.com) и создайте новый приватный (Private) или публичный репозиторий, например `my-openlogbook`.
2. В терминале на вашем компьютере (в папке `c:\LogBook`) выполните команды:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: OpenLogBook v1.0"
   git branch -M main
   git remote add origin https://github.com/ВАШ_ЛОГИН/my-openlogbook.git
   git push -u origin main
   ```

### Шаг 2. Развертывание на Render.com

1. Зарегистрируйтесь на [render.com](https://render.com) (можно войти через ваш аккаунт GitHub в 1 клик).
2. В панели управления Render нажмите синюю кнопку **New +** в верхнем правом углу и выберите пункт **Blueprint**.
3. Выберите ваш репозиторий `my-openlogbook` из списка.
4. Render автоматически прочитает файл `render.yaml` из репозитория и настроит два сервиса:
   - **openlogbook-api** (бэкенд FastAPI на Python 3.12).
   - **openlogbook-client** (клиентская часть React PWA).
5. Нажмите **Apply**.
6. Через 2–3 минуты сборка завершится, и Render выдаст вам постоянную защищенную ссылку вида:
   `https://openlogbook-client.onrender.com`

## Вариант 2: Деплой на Railway.app

Если вы предпочитаете сервис [Railway.app](https://railway.app):

1. Зайдите на **Railway.app** и авторизуйтесь через GitHub.
2. Нажмите **New Project** $\rightarrow$ **Deploy from GitHub repo**.
3. Выберите ваш репозиторий `my-openlogbook`.
4. Railway автоматически обнаружит `Dockerfile` в папках `backend` и `frontend` и развернет контейнеры.
5. В настройках вкладки *Settings* сгенерируйте домен (*Generate Domain*).

## Вариант 3: Собственный VPS-сервер (Ubuntu Linux 22.04 / 24.04)

Если вы арендуете свой VPS (например, на Timeweb Cloud, Selectel, Beget или Hetzner за 200–400 руб/мес):

1. Подключитесь к вашему серверу по SSH:
   ```bash
   ssh root@IP_ВАШЕГО_СЕРВЕРА
   ```
2. Установите Docker и Docker Compose:
   ```bash
   apt update && apt install -y docker.io docker-compose git
   ```
3. Склонируйте ваш репозиторий:
   ```bash
   git clone https://github.com/ВАШ_ЛОГИН/my-openlogbook.git /opt/logbook
   cd /opt/logbook
   ```
4. Запустите проект через Docker Compose:
   ```bash
   docker-compose up -d --build
   ```
5. Для привязки вашего собственного домена и автоматического получения бесплатного SSL-сертификата Let's Encrypt установите Nginx Certbot:
   ```bash
   apt install -y certbot python3-certbot-nginx
   certbot --nginx -d pilot-logbook.yourdomain.com
   ```

## Как установить логбук на iPhone, iPad и Android (PWA)

OpenLogBook спроектирован по стандарту **Progressive Web App (PWA)** с локальной базой данных Dexie.js (IndexedDB). Это значит, что он устанавливается на любое устройство как нативное приложение без App Store / Google Play и сохраняет все полеты даже в режиме полета (Airplane Mode в кабине).

### На iPhone и iPad (Safari):
1. Откройте в браузере Safari ссылку вашего приложения (например, `https://openlogbook-client.onrender.com`).
2. Внизу экрана нажмите кнопку **«Поделиться»** (иконка квадрата со стрелкой вверх).
3. Пролистайте список вниз и нажмите **«На экран «Домой»»** (*Add to Home Screen*).
4. Нажмите **«Добавить»**. На рабочем столе появится иконка OpenLogBook с полноэкранным интерфейсом без рамок браузера.

### На Android (Chrome):
1. Откройте ссылку приложения в Google Chrome.
2. В правом верхнем углу нажмите меню с тремя точками $\rightarrow$ **«Установить приложение»** (*Install app*).

## Как работает синхронизация в кабине (Cockpit Mode)
- **В кабине без интернета:** вы спокойно открываете приложение, вносите времена OUT/OFF/ON/IN, посадки и замечания. Все записи мгновенно сохраняются в защищенную память устройства. В верхнем статус-баре горит индикатор `Кабина (Офлайн)`.
- **По прилету в гостиницу или аэропорт:** как только телефон или планшет ловит Wi-Fi или сотовую сеть, статус меняется на `Онлайн`, и фоновый движок `syncEngine` автоматически передает все накопленные рейсы на ваш сервер.
