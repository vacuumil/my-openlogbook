# ✈️ OpenLogBook — Цифровая лётная книжка пилота

**OpenLogBook** — независимая, открытая и бесплатная электронная лётная книжка (Pilot Logbook), спроектированная пилотами для пилотов. Работает на смартфонах и ПК, не требует платных подписок и работает на 100% офлайн прямо в кабине самолёта.

---

## 🌟 Ключевые возможности

* **📱 PWA (Progressive Web App):** Устанавливается в один клик на домашний экран **iPhone** или **Android** как нативное приложение без необходимости платить \$99/год за Apple Developer аккаунт.
* **📵 100% Offline-First:** Полнофункциональный ввод рейсов и доступ ко всем записям даже при включенном «Авиарежиме» в воздухе.
* **🌙 Cockpit Night Mode:** Специальная палитра для ночной кабины (глубокий черный фон OLED + красная индикация), не ослепляющая пилота в темноте.
* **✨ Автоматический расчет Night Time:** Точный расчет ночного налёта по окончанию гражданских сумерек (Civil Twilight, солнце ниже -6°) и ортодромической дуге маршрута (Great Circle).
* **🌍 Встроенная офлайн-база аэропортов:** Координаты, ICAO/IATA коды и часовые пояса крупнейших аэропортов мира прямо в приложении.
* **🛡️ Контроль квалификаций (Currency):** 
  * Оценка правила **90 дней / 3 посадки** (EASA FCL.060, FAA 61.57) по каждому типу ВС, с датой окончания.
  * Сроки действия **Medical (ВЛЭК)**, **LPC / OPC**, виз и паспортов с индикацией оставшихся дней.
* **🔎 Единая фильтрация:** поиск `UUEE-OMDB` в обе стороны, по IATA и бортам, периоды, типы ВС, роли, PF/PM, заходы, ночные рейсы. Выборка общая для книжки и карты, её можно экспортировать.
* **🗺️ Карта маршрутов:** панель деталей, топ маршрутов и аэродромов, раскраска по типу и году, воспроизведение истории полётов, корректные маршруты через 180°.
* **📊 Главная панель:** предупреждения о сроках, лимиты налёта EASA ORO.FTL.210 (справочно), сравнение периодов и личные рекорды.
* **🧾 Черновики из плана:** рейсы месячного плана попадают в книжку черновиками с плановым временем в UTC и ночью; после полёта пилот подтверждает их.
* **🖥️ Тренажёр и наземная подготовка:** отдельные записи вне налёта; сессии FFS учитываются в правиле 90 дней.
* **🖨️ Печать книжки:** PDF в колонках EASA (AMC1 FCL.050) или лётной книжки РФ, с итогами и переносом на каждой странице.
* **📈 Аналитика:** итоги года с рекордами и картой, сравнение лет по месяцам, прогноз лимитов по плану, погода для ближайших рейсов.
* **❓ Справка** внутри приложения: меню профиля → «Справка».
* **⏱️ Рабочее время:** загрузка месячного плана в PDF, редактируемая таблица, рейсы из книжки, предварительный расчёт по вашим ставкам и выгрузка в Excel (CSV).
* **⌨️ Горячие клавиши:** `N` новый рейс, `/` поиск.
* **🐳 Self-Hosted & Multi-User:** Разворачивается в Docker за пару минут на собственном сервере (VPS) с защищенным доступом для вас и ваших коллег.

## 🚀 Быстрый старт (Разработка и запуск)

### 1. Локальный запуск в один клик (PowerShell)
```powershell
# Запуск бэкенда и PWA фронтенда одной командой:
.\start-dev.ps1
```
* **Приложение (PWA):** `http://localhost:3000`
* **API Документация (Swagger):** `http://localhost:8000/api/v1/docs`

### 2. Запуск на сервере

Только бэкенд и база для разработки поднимаются через `docker compose up -d`. Полный стек для сервера:

```bash
cp .env.example .env                  # POSTGRES_PASSWORD и DOMAIN
cp backend/.env.example backend/.env  # ENVIRONMENT=production, SECRET_KEY, ENCRYPTION_KEY
docker compose -f docker-compose.prod.yml -f docker-compose.https.yml up -d --build
```

> **HTTPS обязателен.** Браузеры не запускают service worker по обычному `http://`, поэтому установка на телефон и офлайн-режим работают только на домене с HTTPS. `docker-compose.https.yml` получает сертификат автоматически, домен должен указывать на сервер.

Подробности, обновление и резервное копирование описаны в [docs/DEPLOYMENT_GUIDE.md](docs/DEPLOYMENT_GUIDE.md).

### 3. Тесты

```bash
cd backend && pip install -r requirements-dev.txt && pytest
cd frontend && npm test
```

## 📲 Установка PWA на телефон

### На iPhone (iOS Safari):
1. Откройте адрес вашего сервера в **Safari**.
2. Нажмите кнопку **«Поделиться»** (иконка квадрата со стрелкой вверх внизу экрана).
3. Прокрутите вниз и выберите **«На экран "Домой"»** (Add to Home Screen).
4. Теперь приложение запускается в полноэкранном режиме без адресной строки Safari и доступно офлайн!

### На Android (Google Chrome):
1. Откройте адрес вашего сервера в **Chrome**.
2. В появившемся внизу баннере нажмите **«Установить приложение»** (или в меню «три точки» -> «Установить на главный экран»).

## 🛠️ Стек технологий
* **Frontend:** React 19, TypeScript, Vite, Tailwind CSS, Lucide Icons
* **Offline Storage:** IndexedDB (Dexie.js), Workbox PWA Service Worker
* **Backend:** Python 3.12, FastAPI, SQLAlchemy 2.0 (async), Pydantic v2
* **Database:** PostgreSQL 16
* **Deployment:** Docker, Docker Compose, Caddy (HTTPS)
